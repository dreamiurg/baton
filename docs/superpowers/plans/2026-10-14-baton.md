# baton Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A shareable Claude Code mod that adds `/bring` to Claude Desktop's Code tab: a docked Bring page that copies Code sessions from the user's other Desktop profiles (other Anthropic accounts) into the current window, with full history.

**Architecture:** One TypeScript hooks module (`hooks/register.tsx`) wires events and draws the Bring page. All logic lives in pure modules under `lib/` that take their I/O as arguments (`Fs`, `Run`), so `node --test` covers them without the engine. The bring itself forks the transcript on disk and sends `claude://resume?session=<fork>` to the window's own Desktop process with a JXA Apple Event; Desktop does the import.

**Tech Stack:** TypeScript (erasable syntax only), Claude Code mod API (hooks modules, `$.fs`, `$.process.run`, `$.ui`), Node 22 `node --test --experimental-strip-types` for unit tests, `claude plugin validate` / `claude plugin test`, GitHub Actions, lefthook-free plain git hook.

**Spec:** `docs/superpowers/specs/2026-10-14-baton-design.md` (read it first; this plan argues from it). Visual design: https://claude.ai/artifact/Uyz8y4NND7SVdFCJ8P1Smw (private to the author; the spec's "The Bring page" section describes it fully).

## Global Constraints

- macOS only. Desktop profiles live in `~/Library/Application Support/Claude*`; transcripts in `~/.claude/projects/<cwd with every non-alphanumeric char replaced by "-">/<cliSessionId>.jsonl`.
- No runtime npm dependencies. Dev dependencies only: `typescript@5.6.3`, `@types/node@22`.
- TypeScript must be erasable (no `enum`, no `namespace`, no parameter properties) so Node 22 strips it; relative imports carry the `.ts` extension.
- Plugin name `baton`, command `/bring`, Pane id `baton-bring`, Pane title `Bring a session here`.
- baton never writes Desktop's own files (`claude-code-sessions/**`, `config.json`, …). It writes only: forked transcripts and sidecar copies under `~/.claude/projects/`, `~/.local/state/baton/usage/<profileDir>.json`.
- No personal data in the repo: no real emails, account/org UUIDs, profile names other than `Claude` and a generic `Claude-Work` in tests and docs.
- Config file `~/.config/baton/config.json`, shape `{"profiles": {"<profileDir>": {"label": "Personal", "email": "me@example.com"}}}`; every field optional.
- Copy follows the spec: buttons "Bring", "Bring all N", "Retry"; states "Queued", "Opening…", "Opened"; footer "Bring makes a copy here. The original stays in <label>."
- Conventional commits; every commit ends with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. `/bring` typed in a terminal Claude Code session (no Desktop ancestor process): one clear line "Run /bring in a Claude Desktop Code session.", no Pane, no crash. Test in Task 5 (`findSelf` returns null) and Task 7 (command answer).
2. A record Desktop is writing at that moment (truncated JSON), or a record whose transcript was deleted or whose worktree folder is gone: that one row is skipped, the rest of the page renders. Test in Task 3.
3. A transcript whose message text contains the old session id (Claude printed it): only `"sessionId":"<old>"` keys change; the text stays. Test in Task 2.
4. A friend with zero config and only one Desktop profile: page says "No other Claude profiles found." and nothing breaks; with a profile missing from config, its label is the dir name with dashes as spaces and no email. Test in Task 3 and Task 7.
5. A usage reading saved before the weekly reset (resetsAt in the past): show 0%, not the stale 100%. Test in Task 4.

```ts
// Rewrites only the top-level "sessionId":"<old>" keys; message text that quotes the id is escaped JSON and never matches.
export function forkTranscript(text: string, oldId: string, newId: string): string {
  const needle = `"sessionId":"${oldId}"`
  const replacement = `"sessionId":"${newId}"`
  const out: string[] = []
  for (const line of text.split('\n')) {
    if (line.includes('"type":"bridge-session"') && isBridgeSession(line)) continue
    out.push(line.includes(needle) ? line.split(needle).join(replacement) : line)
  }
  return out.join('\n')
}

function isBridgeSession(line: string): boolean {
  try {
    return (JSON.parse(line) as { type?: unknown }).type === 'bridge-session'
  } catch {
    return false
  }
}
```

```ts
import type { Fs, FsEntry } from '../../lib/types.ts'

export function memFs(files: Record<string, string>): Fs & { files: Record<string, string> } {
  const dirs = new Set<string>()
  for (const p of Object.keys(files)) {
    const parts = p.split('/')
    for (let i = 1; i < parts.length; i++) dirs.add(parts.slice(0, i).join('/'))
  }
  return {
    files,
    list: async path => {
      const seen = new Map<string, FsEntry>()
      for (const p of [...Object.keys(files), ...dirs]) {
        if (!p.startsWith(path + '/')) continue
        const name = p.slice(path.length + 1).split('/')[0]!
        const full = `${path}/${name}`
        seen.set(name, { name, kind: dirs.has(full) ? 'dir' : 'file' })
      }
      if (!seen.size && !dirs.has(path)) throw new Error(`ENOENT ${path}`)
      return [...seen.values()]
    },
    read: async path => {
      const t = files[path]
      if (t === undefined) throw new Error(`ENOENT ${path}`)
      return t
    },
    exists: async path => path in files || dirs.has(path),
    size: async path => (files[path] ?? '').length,
    write: async (path, text) => {
      files[path] = text
    },
  }
}
```

```ts
  const m = /^claude-([a-z]+)-(\d+)(?:-(\d+))?/.exec(id ?? '')
  if (!m) return id ?? ''
  const [, family = '', major = '', minor] = m
  return `${family.charAt(0).toUpperCase()}${family.slice(1)} ${major}${minor ? '.' + minor : ''}`
}

export function prLabel(rec: Rec): string | null {
  const last = rec.prs && rec.prs.length ? rec.prs[rec.prs.length - 1] : undefined
  const n = last?.prNumber ?? rec.prNumber
  const state = (last?.state ?? rec.prState ?? '').toLowerCase()
  return n ? `#${n}${state ? ' ' + state : ''}` : null

async function listDirs(fs: Fs, path: string): Promise<string[]> {
  try {
    return (await fs.list(path)).filter(e => e.kind === 'dir').map(e => e.name)
  } catch {

  }

  }

export async function readSessions(fs: Fs, home: string, profilePath: string): Promise<{ sessions: Session[]; orgId: string | null }> {
  const root = `${profilePath}/claude-code-sessions`
  const sessions: Session[] = []
  let orgId: string | null = null
  let newest = -1
  for (const acct of await listDirs(fs, root)) {
    for (const org of await listDirs(fs, `${root}/${acct}`)) {
      const dir = `${root}/${acct}/${org}`
      for (const f of await fs.list(dir).catch(() => [])) {
        if (f.kind !== 'file' || !f.name.startsWith('local_') || !f.name.endsWith('.json')) continue
        let rec: Rec
        try {
          rec = JSON.parse(await fs.read(`${dir}/${f.name}`)) as Rec
        } catch {
          continue // Desktop may be mid-write; skip this record only
        }
        const id = rec.cliSessionId
        if (!id || rec.isArchived) continue
        const transcriptPath = await findTranscript(fs, home, rec, id)
        if (!transcriptPath) continue
        const last = rec.lastActivityAt ?? 0
        if (last > newest) {
          newest = last
          orgId = org
        }
        const limited = rec.error && LIMIT.test(rec.error) ? rec.errorAt ?? last : null
        sessions.push({
          cliSessionId: id,
          title: rec.title ?? 'Untitled session',
          folder: (rec.originCwd ?? rec.cwd ?? '').split('/').filter(Boolean).pop() ?? '',
          branch: rec.branch ?? rec.sourceBranch ?? '',
          lastActivityAt: last,
          limitedAt: limited,
          resetText: limited !== null ? RESETS.exec(rec.error ?? '')?.[1] ?? null : null,
          pr: prLabel(rec),
          model: modelLabel(rec.model),
          tokensApprox: Math.round((await fs.size(transcriptPath)) / 4),
          transcriptPath,
        })
      }
    }
  }
  sessions.sort((a, b) =>
    a.limitedAt !== null && b.limitedAt !== null ? b.limitedAt - a.limitedAt
    : a.limitedAt !== null ? -1
    : b.limitedAt !== null ? 1
    : b.lastActivityAt - a.lastActivityAt)
  return { sessions, orgId }
}
```

```ts
import type { Usage } from './types.ts'

type Reading = { percent: number; resetsAt: string | null; asOf: number }
type Sample = { t: number; org: string; u?: { sd?: number } }

function parse<T>(text: string | null): T | null {
  if (text === null) return null
  try {
    return JSON.parse(text) as T
  } catch {
    return null
  }
}

export function pickUsage(input: {
  baton: string | null
  planHistory: string | null
  orgId: string | null
  limitReset: string | null
  now: number
  formatReset: (iso: string) => string
}): Usage | null {
  const reading = parse<Reading>(input.baton)
  if (reading && typeof reading.percent === 'number') {
    const isPastReset = reading.resetsAt !== null && Date.parse(reading.resetsAt) < input.now
    return {
      percent: isPastReset ? 0 : reading.percent,
      resetLabel: reading.resetsAt && !isPastReset ? input.formatReset(reading.resetsAt) : null,
      asOf: reading.asOf,
      source: 'baton',
    }
  }
  const samples = parse<{ samples?: Sample[] }>(input.planHistory)?.samples
  const newest = Array.isArray(samples)
    ? samples.filter(s => typeof s.u?.sd === 'number' && (!input.orgId || s.org === input.orgId)).sort((a, b) => b.t - a.t)[0]
    : undefined
  if (newest) return { percent: newest.u!.sd!, resetLabel: null, asOf: newest.t, source: 'desktop' }
  if (input.limitReset !== null) return { percent: 100, resetLabel: input.limitReset, asOf: input.now, source: 'limit-error' }
  return null
}

export function serializeReading(rateLimits: readonly { kind: string; percentUsed: number; resetsAt?: string }[], now: number): string | null {
  const week = rateLimits.find(r => r.kind === 'seven_day')
  return week ? JSON.stringify({ percent: week.percentUsed, resetsAt: week.resetsAt ?? null, asOf: now }) : null
}
```

```ts
import type { Run, Self } from './types.ts'

export type Proc = { pid: number; ppid: number; command: string }

const PROFILE = /\/Library\/Application Support\/([^/]+)\/claude-code\//
const DESKTOP = /\/Contents\/MacOS\/Claude(?:\s|$)/

export function parsePs(line: string): Proc | null {
  const m = /^\s*(\d+)\s+(\d+)\s+(.+)$/.exec(line)
  return m ? { pid: Number(m[1]), ppid: Number(m[2]), command: m[3]! } : null
}

export function findSelf(chain: readonly Proc[], home: string): Self | null {
  const profileDir = chain.map(p => PROFILE.exec(p.command)?.[1]).find(Boolean)
  const desktop = chain.find(p => DESKTOP.test(p.command))
  if (!profileDir || !desktop) return null
  return { home, profileDir, profilePath: `${home}/Library/Application Support/${profileDir}`, desktopPid: desktop.pid }
}

export async function readSelf(run: Run): Promise<Self | null> {
  const start = await run(['/bin/sh', '-c', 'echo "$PPID"; echo "$HOME"'])
  const [pidText = '', home = ''] = start.stdout.trim().split('\n')
  const chain: Proc[] = []
  let pid = Number(pidText)
  for (let i = 0; i < 8 && pid > 1; i++) {
    const out = await run(['/bin/ps', '-o', 'pid=,ppid=,command=', '-p', String(pid)])
    const proc = out.exitCode === 0 ? parsePs(out.stdout.trim()) : null
    if (!proc) break
    chain.push(proc)
    pid = proc.ppid
  }
  return findSelf(chain, home)
}
```

```ts
import { forkTranscript } from './fork.ts'
import type { Fs, Run, RunResult, Self, Session } from './types.ts'
import { serializeReading } from './usage.ts'

export type BringDeps = { fs: Fs; run: Run; sleep: (ms: number) => Promise<void> }
export type BringResult = { ok: true; forkId: string } | { ok: false; forkId: string | null; reason: string }

// Sends a GURL (open URL) Apple Event to one process id, so the link reaches this window even when several Desktop windows run.
export const GURL_SCRIPT = [
  "ObjC.import('Foundation');",
  'function run(argv) {',
  '  var target = $.NSAppleEventDescriptor.descriptorWithProcessIdentifier(parseInt(argv[0]));',
  '  var ev = $.NSAppleEventDescriptor.appleEventWithEventClassEventIDTargetDescriptorReturnIDTransactionID(0x4755524c, 0x4755524c, target, -1, 0);',
  '  ev.setParamDescriptorForKeyword($.NSAppleEventDescriptor.descriptorWithString(argv[1]), 0x2d2d2d2d);',
  '  var err = Ref();',
  '  var res = ev.sendEventWithOptionsTimeoutError(0x1, 10, err);',
  "  return (res && !res.isNil()) ? 'sent' : 'error';",
  '}',
].join('\n')

async function must(p: Promise<RunResult>): Promise<RunResult> {
  const r = await p
  if (r.exitCode !== 0) throw new Error(r.stderr.trim() || `exit ${r.exitCode}`)
  return r
}

const message = (err: unknown) => (err instanceof Error ? err.message : String(err))

export async function bringSession(s: Session, self: Self, deps: BringDeps, forkId: string | null = null): Promise<BringResult> {
  const dir = s.transcriptPath.slice(0, s.transcriptPath.lastIndexOf('/'))
  const id = forkId ?? (await deps.run(['/usr/bin/uuidgen'])).stdout.trim().toLowerCase()
  if (!id) return { ok: false, forkId: null, reason: "Couldn't create a session id (uuidgen failed)." }
  try {
    const target = `${dir}/${id}.jsonl`
    if (!(await deps.fs.exists(target))) {
      const text = await deps.fs.read(s.transcriptPath)
      await deps.fs.write(`${target}.tmp`, forkTranscript(text, s.cliSessionId, id))
      await must(deps.run(['/bin/mv', `${target}.tmp`, target]))
      const sidecar = `${dir}/${s.cliSessionId}`
      if (await deps.fs.exists(sidecar)) await must(deps.run(['/bin/cp', '-R', sidecar, `${dir}/${id}`]))
    }
  } catch (err) {
    await deps.run(['/bin/rm', '-f', `${dir}/${id}.jsonl.tmp`])
    return { ok: false, forkId: null, reason: `Couldn't copy the transcript: ${message(err)}` }
  }

  const sent = await deps.run(['/usr/bin/osascript', '-l', 'JavaScript', '-e', GURL_SCRIPT, String(self.desktopPid), `claude://resume?session=${id}`])
  if (sent.exitCode !== 0 || !sent.stdout.includes('sent')) {
    return { ok: false, forkId: id, reason: "Couldn't reach this window's Claude app. Retry, or restart the window." }
  }

  const sessionsDir = `${self.profilePath}/claude-code-sessions`
  for (let i = 0; i < 20; i++) {
    const found = await deps.run(['/bin/sh', '-c', 'ls "$1"/*/*/local_"$2".json', 'sh', sessionsDir, id])
    if (found.exitCode === 0) return { ok: true, forkId: id }
    await deps.sleep(500)
  }
  return { ok: false, forkId: id, reason: "Desktop didn't open it. Retry sends the link again." }
}

export async function writeUsage(deps: BringDeps, self: Self, rateLimits: readonly { kind: string; percentUsed: number; resetsAt?: string }[], now: number): Promise<void> {
  const text = serializeReading(rateLimits, now)
  if (text === null) return
  const dir = `${self.home}/.local/state/baton/usage`
  await deps.run(['/bin/mkdir', '-p', dir])
  await deps.fs.write(`${dir}/${self.profileDir}.json`, text)
}
```

```tsx
    read: (p: string) => Promise<string>
```

````markdown
# baton

Ran out of weekly Claude quota on one account? Open the Claude Desktop window of another account, type `/bring`, and pick up your stalled Code sessions there with their full history.

![The Bring page](docs/bring-page.png)

## What it does

`/bring` opens a panel beside the conversation. It lists your other Claude Desktop accounts with their weekly usage, and under each one its live Code sessions, the ones that hit their limit first. **Bring** copies a session into the window you're in and opens it. The original stays where it was.

## You need

- macOS and Claude Desktop with the Code tab.
- One Desktop window per account, each on its own profile. The default profile is `~/Library/Application Support/Claude`. Start another with:

  ```bash
  open -n -a Claude --args --user-data-dir="$HOME/Library/Application Support/Claude-Work"
  ```

  and sign in to the other account in that window. Any folder name starting with `Claude` works.

## Install

In a terminal Claude Code session:

```
/plugin install baton --marketplace dreamiurg/baton
```

Answer `y` to add the marketplace and pick the user scope. Every Desktop window loads it from then on.

## Optional: names and emails

baton labels each account by its profile folder. To show your own names and emails, create `~/.config/baton/config.json`:

```json
{
  "profiles": {
    "Claude": { "label": "Personal", "email": "me@example.com" },
    "Claude-Work": { "label": "Work", "email": "me@work.example" }
  }
}
```

## Good to know

- Bring makes a copy. Continuing in both windows makes two separate conversations.
- The first message after a bring rebuilds the prompt cache on the new account, so a long session costs more tokens once.
- Weekly usage for an account appears after baton has run in that account's window once.
- Only Code-tab sessions. claude.ai chats and Cowork sessions aren't covered.

git config core.hooksPath .githooks
scripts/lay-types.sh
npm run check && claude plugin test .
```
````
